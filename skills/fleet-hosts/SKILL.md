---
name: fleet-hosts
description: Resolve fleet machine nicknames, SSH to a computer, or run a command or agent on another machine, including on Rolly, Mooney/mua, Sunny, Jelly or MBP.
---

To reach another fleet machine or resolve a machine nickname, run `darma hosts` (or `darma hosts <name>`). Prefer its T3 linked environment to run an agent there and SSH to run a command. Use the printed SSH login; never guess one.
