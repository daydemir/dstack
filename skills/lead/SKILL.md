---
name: lead
description: Lead one completable goal as a thread the chief of staff manages, or one the user starts.
---

Own one goal that can be finished, from "fetch some info" to "release the new app version". Say what "done" means first.

Log to `inbox/<your thread>.md` beside the chief of staff's decision log (project `handoffs/`; its top links the chief-of-staff thread). Put what the user must do or decide under a `NEEDS DENIZ` line at the top. Never message the chief of staff.

Message another thread only when it must act now: a review, a gate, a blocker on its work. Put FYIs and status in its inbox file instead, since every message wakes that thread and reopens it if it was settled.

Settle your thread whenever nothing you started is still running, even mid-goal; a child's completion, a schedule or a message reopens it. A schedule you create ends each run the same way.

When the user is done with you, send them back to the chief-of-staff thread (link). When the goal lands, say so, settle your thread (`thread-manager`), and stop.
